# ✅ Task Manager App

A simple and interactive **Task Manager Web Application** built using HTML, CSS, and JavaScript. This project was developed while learning how to fetch data from an API and work with asynchronous JavaScript.

The application allows users to add new tasks, view the task list, edit existing tasks, and delete tasks through a clean, dark-themed interface.

## ✨ Features

- ➕ **Add Tasks** — Create and add new tasks to the list.
- 📋 **View Tasks** — Display the available tasks in an organized list.
- ✏️ **Edit Tasks** — Update existing task details.
- 🗑️ **Delete Tasks** — Remove tasks from the list.
- 🌐 **API Fetching** — Practice fetching and handling data from an API.
- 🎨 **Dark UI** — A simple, dark-themed interface with clear action buttons.

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and layout
- **JavaScript** — Application logic and DOM manipulation
- **Fetch API** — Retrieving and handling data from an API

## 📸 Application Preview

The application provides a task input field, an Add button, and a task list with Edit and Delete actions for individual tasks.
